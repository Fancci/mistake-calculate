# 错题分布统计器

> 批完一位学生就点一次错题，全部批完自动汇总「错题集中在哪几题」

一款面向**教师批改作业**场景的纯前端网页工具。批完一位学生的作业就记录一次他的错题，
全部批完后自动统计出「错题集中在哪几题、每题多少人错、属于大量 / 中量 / 小量错误」。

**单文件 · 零依赖 · 离线可跑** —— 双击 `index.html` 即可使用，不需要安装任何东西、
不需要联网、不需要后端。

## ✨ 核心特点

- **题量灵活**：开局输入本次作业一共几题（1~200），界面按题量自动排布，每次作业互不影响
- **一人一点**：屏幕一次只显示一位学生的题号网格，点一下题号 = 这题做错，再点一下取消
- **缺交单列**：不预设全班人数；缺交的学生按「缺交」键即可，不参与错误率计算
- **自动分级**：按错误率自动划为大量 / 中量 / 小量错误，阈值可在结果页现场调整并实时重算
- **错题排名**：直接给出错误最集中的题目前三名
- **一键导出 CSV**：汇总表可直接用 Excel 打开（带 UTF-8 BOM，不乱码）
- **打印友好**：结果页可直接 `Ctrl + P` 打印成白底报告

## 🚀 使用方式

1. **开局**：填作业名（可选）+ 本次题数 → 点「开始录入」
2. **逐人录入**：点一下题号变红 = 这题错，再点一下取消；什么都没点 = 全对；缺交点「缺交」键。
   按 `回车` = 下一位；右侧花名册可点任意一行跳回去修改
3. **看结果**：点「查看统计结果」→ 概览卡 + 错题集中排名 + 逐题明细；点「导出 CSV」存表

双击 `index.html` 即可开始，无需联网。

## 📐 统计口径（重要）

| 项 | 规则 |
|---|---|
| **错误率分母** | **实交人数**（缺交同学不进分母，单独计数） |
| 实交 | 非缺交的记录数 |
| 缺交 | 只按「缺交」键记录，不点任何错题 |
| 分级（默认） | 大量错误 ≥ 50%、中量错误 20% ~ 50%、小量错误 < 20% |
| 无错误档 | **0 人做错的题单独列为「无错误」**，不归入小量错误 |
| 排名 | 错误人数降序，人数相同时按题号升序，前三名高亮 |
| 题号 | 固定连续 1 ~ N，N 在开局输入 |

阈值可在结果页随时修改，改后立即重算（校验：中量阈值必须小于大量阈值）。


刻意采用单文件：交付给老师时只需发一个文件，不会出现「只传了 HTML、忘了传 JS / CSS」
导致页面没样式的翻车情况。

## 🔒 隐私

本工具**不联网、无后端、不做本地持久化**。学生姓名（可选填）与错题记录只存在于浏览器
内存中，不经过任何服务器，关闭页面即消失 —— **请务必在关闭前导出 CSV 留档**。
（检测到已有录入记录时，浏览器会弹「确定离开？」提示，防止误关丢数据。）

## 🌐 浏览器要求

Chrome / Edge / Firefox / Safari 等现代浏览器均可；手机、平板浏览器同样可用。

## 🧪 测试情况

在真实浏览器（系统 Edge + pyppeteer）中跑了 **66 项断言**，覆盖场景：

- 主流程：含缺交、全对、重复点击取消（toggle）、上一位 / 下一位来回穿梭不产生多余空记录
- 边界：全员缺交（除零保护，显示 `—` 而非 `NaN`）、全员全对、1 题、60 题
- 异常输入：题数 300（超上限）、非数字
- 阈值：非法阈值提示、调整后实时重算
- 导出：CSV 内容逐字段校验、UTF-8 BOM、文件名非法字符清洗
